# MobilityTicketing – Lecture 9

PostgreSQL 17 booking experiments. The setup and supplied checks come from the Lecture 9 starter.

Run `docker compose up -d --wait postgres`, then `docker compose exec -T postgres bash /lab/run.sh reset`.

Use `bash /lab/run.sh check` inside the container to run the supplied checks. The SQL approaches are saved in `sql/variants/` and the experiment notes are in `docs/evidence.md`.
